🛡️ KORVEX Anti-Chatter

Elimina el rebote de teclas en teclados mecánicos.
Disponible para Windows y Linux.

🚀 Instalación en Linux (Debian/Ubuntu)

Opción A: Añadir repositorio APT (recomendado)

Copia y pega estos comandos en una terminal:

# Añadir clave pública
wget -O- https://mikicolmena.github.io/KORVEX-Anti-Chatter/public.key | sudo gpg --dearmor -o /usr/share/keyrings/korvex.gpg

# Añadir repositorio
echo "deb [signed-by=/usr/share/keyrings/korvex.gpg] https://mikicolmena.github.io/KORVEX-Anti-Chatter stable main" | sudo tee /etc/apt/sources.list.d/korvex.list

# Actualizar e instalar
sudo apt update
sudo apt install korvex-antichatter

Después de esto, las actualizaciones se realizarán con sudo apt update && sudo apt upgrade.

Opción B: Descargar el .deb directamente

Ve a la página de Releases y descarga el archivo KorvexAntiChatter.deb. Luego instálalo con:

sudo apt install ./KorvexAntiChatter.deb

Nota: con este método no se reciben actualizaciones automáticas.

🪟 Instalación en Windows

Descarga KorvexAntiChatter.exe desde Releases y ejecútalo.
